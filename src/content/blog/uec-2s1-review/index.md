## 1年生からの変化

正直1年(特に後期)と比べると、総合的な忙しさには天と地ほどの差があります。
ただ、専門科目など1科目そのものが難しくなった感じはあります。

- **基礎科学実験が消えた** — これのおかげで週の負荷が激減しましたね。デカすぎる...

- **総合文化科目を自分で組む必要が出てくる** — え！？理系なのに文系科目を！？となりましたが、マジです。
- **金曜が全休になった** — 予想外の全休でした。毎週が3連休。

## 必修科目

### 対面

#### 確率論

[シラバス ↗](https://kyoumu.office.uec.ac.jp/syllabus/2026/31/31_21122101.html)

| 項目   | 詳細        |
| ------ | ----------- |
| 出席   | あり        |
| 課題   | 授業内 & 外 |
| 負担   | 中          |
| テスト | 中間・期末  |
| 成績   | 良          |

条件付き確率やベイズの定理から始まり、独立性やモーメント母関数、中心極限定理及び様々な分布について学びます。数学A・Bの知識に加えて、微分積分学第一・第二の知識が必要です。

課題は授業の最初に問題が紙で配られ、それを授業の終わりに提出するパターンと次の授業の最初に提出するパターンの2つがありました。前者は、解き切っているかどうかはたぶん成績に関係ないと思います。

そして、テストの難易度は正直**レベチ**でした。時間内に全部解き終わらない前提で作られてるので、本当に取れるところで取るしかないです。自分は記述や証明は捨てました(なるべくしてなった成績)。

1年後期の毎日数学があった時代(離散→解析→数円→線形→微積)と比べて2年前期の数学はこれだけだったので、もう少し力入れられたかなぁと感じますね...

[シラバス ↗](https://kyoumu.office.uec.ac.jp/syllabus/2026/31/31_21013116.html)

正式名称は**Academic English for the Second Year Ⅰ**です。AESと略す場合も。
AWE・ASEよりさらに学術的な英語を扱います。

Classroomが実質使われていなかったため、提出物や講義資料の管理がメール中心でやや大変でした。正確にはClassroom自体はあるにはあるのですが、1つも投稿がないまま終わりました(？)

最終的に研究内容についてのプレゼンを行います。情報の管理が大変でしたが、提出物もマイルドで他のAE2Yの先生と比べると負担は穏やかな方だと思います。

あと6月上旬に授業内で**TOEIC IP**を実施します。成績には10%しか影響しません。

#### プログラミング通論

[シラバス ↗](https://kyoumu.office.uec.ac.jp/syllabus/2026/31/31_21122110.html)

| 項目   | 詳細       |
| ------ | ---------- |
| 出席   | なし？     |
| 課題   | 授業外     |
| 負担   | 中         |
| テスト | 中間・期末 |
| 成績   | 秀         |

基礎プロの後半で扱ったC言語をさらに学習します。C言語に限らず、他のプログラミング言語でも重要な

- スタック・キュー・デク
- 再帰とその除去
- リスト
- ソート
- 探索

といったデータ構造やアルゴリズムについても学びます。

テストはまさかの**手書き**です。手書きエディタ、環境構築が簡単ですね。
でもセミコロン忘れみたいな細かなミスより、概念が理解できているかのほうが重要視されます。なので変なミスに怯えすぎる必要はないです。

あと今年度(の期末試験)から、もともとiPadなどの電子機器に講義資料を用意して持ち込み可能だったのですが、それは禁止され**印刷した紙媒体の講義資料のみ**に変更されました。某生成AIのせいでしょうか...🤡

テスト前に、「絶対に出す部分」「範囲の部分」「絶対出さない部分」を示してくれるので見逃さないようにしましょう。
大学からプログラミングの学習を始めた者の目線ですが、体感のテスト難易度は**やや難しい〜難しい**くらいでした。

#### 情報領域演習第二

[シラバス ↗](https://kyoumu.office.uec.ac.jp/syllabus/2026/31/31_21122113.html)

| 項目   | 詳細   |
| ------ | ------ |
| 出席   | あり   |
| 課題   | 授業外 |
| 負担   | 中     |
| テスト | なし   |
| 成績   | 優     |

1つの授業で4種類(!?)の演習を行います。原則として1回でも出席しないと即落単です。やばすぎ

負担と難易度は **L > C > K >> Q** です。

- **Q演習**

    全6回。[プログラミング通論](#プログラミング通論)に対応していて、**C言語**をやります。
    *Programming*のPは既に情報領域演習第一で使ってるので、その次のQを使ったんだと思います。たぶん。

    レポート提出はなく、書いたコードを元にテストを通せばいいので一番楽しかったです。
    ~~「あなたはスタックです。」~~

- **C演習**

    全4回。[計算機通論](#計算機通論)に対応していて、**アセンブリ言語**(MIPS)をやります。
    *Computer*のCだと思います。

    レジスタやスタックポインタ等の細かい部分をみっちり考えてコードを書く必要があります。レポートもあります。
    好きな人にはとことん刺さりそうだけど、苦手な人にとっては地獄みたいな言語だと感じます。

- **L演習**

    全3回。[論理設計学](#論理設計学)に対応していて、主に**回路設計**をやります。
    *Logic*のLだと思います。

    レポートの物量だけでいえば最も大変でした。大量のゲートと配線で数時間溶けました...🤡
    生成AI利用が完全に禁じられています。バレると呼び出しくらいます。気をつけましょう。

- **K演習**

    全2回。[確率論](#確率論)に対応していて、問題演習を行います。
    *Kakuritsu*のK...だよな...？
    レポートは確率論のとても良い復習になりました。2回しかないのが悲しいレベルで。

## 2年後期に向けて

おそらく電通大生活の数年間で時間割的に一番楽な期間だったかもしれないです。でも1年後期を終えた解放感で気を抜くと、色々とまずい科目があるというトラップみたいな仕組みになってますね。

後期は第一希望のコンピュータサイエンスプログラムに(多分)配属され、類専門科目を少しずつ学習し始める時期になるはずです。
どんどん興味分野と大学の授業の距離が近づいてる感じがしていいっすね。GPAもこのまま現状維持でいきたいです。
