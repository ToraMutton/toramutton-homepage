## 1年生からの変化

正直1年(特に後期)と比べると、総合的な忙しさには天と地ほどの差があります。
ただ、専門科目など1科目そのものが難しくなった感じはあります。

- **基礎科学実験が消えた** — これのおかげで週の負荷が激減しましたね。デカすぎる...
- **類共通の専門科目が本格スタート** — 計算機通論・論理設計学など、専門科目が一気に来ます。詳しくは後述。
- **総合文化科目を自分で組む必要が出てくる** — え！？理系なのに文系科目を！？となりましたが、マジです。
- **金曜が全休になった** — 予想外の全休でした。毎週が3連休。

## 必修科目

### 対面

#### 確率論

[シラバス ↗](https://kyoumu.office.uec.ac.jp/syllabus/2026/31/31_21122101.html)

| 項目   | 詳細                  |
| ------ | --------------------- |
| 出席   | あり                  |
| 課題   | 授業内 & 外           |
| 負担   | 中                    |
| テスト | 中間・期末            |
| 成績   | 良(予想) / 素点: TODO |

条件付き確率やベイズの定理から始まり、独立性やモーメント母関数、中心極限定理及び様々な分布について学びます。数学A・Bの知識に加えて、微分積分学第一・第二の知識が必要です。

課題は授業の最初に問題が紙で配られ、それを授業の終わりで提出するパターンと次の授業の最初に提出するパターンの2つがありました。前者は、解き切っているかどうかはたぶん成績には関係ないと思います。

そして、テストの難易度は正直**レベチ**でした。時間内に全部終わらない前提で作られてるので、本当に取れるところで取るしかないです。自分は記述や証明は捨てました。
1年後期の毎日数学があった時代(離散→解析→数円→線形→微積)と比べて2年前記の数学はこれだけだったので、もう少し力入れれたなぁと感じますね...

正式名称は**Academic English for the Second Year Ⅰ**です。AESと略す場合も。
AWE・ASEよりさらに学術的な英語を扱います。

Classroomがなかったため、提出物や講義資料の管理が相当大変でした。正確にはあるにはあるのですが、1つも投稿がないまま終わりました(？)

最終的に研究内容についてのプレゼンを行います。情報の管理が大変でしたが、提出物もマイルドで他のAE2Yの先生と比べると負担は穏やかな方だと思います。

#### プログラミング通論

[シラバス ↗](https://kyoumu.office.uec.ac.jp/syllabus/2026/31/31_21122110.html)

| 項目   | 詳細                  |
| ------ | --------------------- |
| 出席   | なし？                |
| 課題   | 授業外                |
| 負担   | 中                    |
| テスト | 中間・期末            |
| 成績   | 優(予想) / 素点: TODO |

基礎プロの後半で扱ったC言語をさらに学習します。C言語に限らず、他のプログラミング言語でも重要な

- スタック・キュー・デク
- 再帰とその除去
- リスト
- ソート
- 探索

についても学びます。

テストはまさかの**手書き**です。手書きエディタ、環境構築が簡単ですね。
でもセミコロン忘れみたいな細かなミスより、概念が理解できているかのほうが重要視されます。なので変なミスに怯えすぎる必要はないです。

あと今年度(の期末試験)から、持ち込み可能なものが**電子機器含む講義資料 → 印刷した講義資料だけ**になりました。某生成AIのせいでしょうか...🤡

テスト前に、「絶対に出す部分」「範囲の部分」「絶対出さない部分」を示してくれるので見逃さないようにしましょう。
大学からプログラミングの学習を始めた者の目線ですが、体感のテスト難易度は**やや難しい〜難しい**くらいでした。
